# Archi — თიქეთების LiveBoard

Bitrix24-ის დილების (pipeline **23**) ლაივ-ბორდი: პროექტებისა და პორტფოლიო
მენეჯერების ჭრილში თიქეთების რაოდენობები, გრაფიკები და დეტალური ჩამონათვალი.

## გაშვება

სტატიკური გვერდია — build არ სჭირდება, მაგრამ ES-მოდულების გამო `file://`-ით
არ იხსნება; საჭიროა HTTP სერვერი:

```bash
node serve.mjs          # http://localhost:4173
```

## რას აჩვენებს

| მაჩვენებელი | განსაზღვრება |
|---|---|
| თიქეთების რაოდ. | ყველა დილი `CATEGORY_ID = 23` |
| ვადაგადაცილებული თიქ. რაოდ. | ეტაპი `C23:UC_RGEFQ9` (ვადაგადაცილებული) |
| ჩახურული თიქეთები | ეტაპი `C23:WON` + `C23:PREPAYMENT_INVOIC` |
| ვადაგ. ჩახურული თიქეთები | ჩახურული **და** `UF_CRM_1731998758508 = True` |

თარიღის ფილტრი დეფოლტად მუშაობს `BEGINDATE`-ზე (CRM-ის ფილტრში „თარიღიდან“, ბორდზე „დედლაინი“),
რომ რიცხვები CRM-ის სიას ემთხვეოდეს; ველის სელექტორიდან შეიძლება
`DATE_CREATE`-ზე („შექმნის თარიღი“) გადართვა. დეფოლტად ბოლო 1 თვე.

**პორტფოლიო მენეჯერი** — ლისტიდან `111`, ველი `PROPERTY_1299`. მენეჯერის
პროექტები ემთხვევა დილის `UF_CRM_5E1EECDB0571C`-ის მნიშვნელობებს (ლისტის
`NAME` ზუსტად ემთხვევა enum-ის `VALUE`-ს), და ასე ითვლება მისი თიქეთები.

რაოდენობაზე (ან გრაფიკის სეგმენტზე) დაკლიკვით იხსნება სლაიდერი შემდეგი
ველებით: ID, პროექტი, მიმართულება, პრობლემის ჯგუფი, Stage, პორტფოლიო მენეჯერი,
პასუხისმგებელი, თანაპასუხისმგებლები, მოგვარები, მიმდინარე დედლაინი.
სლაიდერიდან შესაძლებელია CSV ექსპორტი.

**კონკრეტულ დილზე გადასვლა**: სლაიდერში სტრიქონზე (ან ID-ზე) დაკლიკვით
დილი იხსნება ბიტრიქსში ახალ ტაბში —
`https://crm.archi.ge/crm/deal/details/{ID}/`.

```bash
node src/verify.mjs     # ადარებს კლიენტის აგრეგაციას სერვერის total-ებს
```

## ორი დეტალი, რაც აუცილებლად უნდა გახსოვდეს

1. **`batch`-ში ფილტრის ოპერატორი უნდა იყოს URL-encoded.** `filter[>=DATE_CREATE]`
   ჩუმად იგნორირდება და **ფილტრის გარეშე** აბრუნებს ყველაფერს — შეცდომის გარეშე.
   `encodeQuery` სწორედ ამიტომ აკოდირებს გასაღებებსაც.
2. **`crm.deal.list` არ აბრუნებს `UF_` ველებს**, თუ ისინი `select`-ში არ ჩაწერე.
